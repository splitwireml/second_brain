## Overview

**Linear** is a project management and issue tracking tool designed for software teams. Known for its clean, fast interface and well-designed empty states.

## Key Facts

- Founded: 2019
- Headquarters: San Francisco, CA
- Type: SaaS project management tool

## Empty State Design

Linear's empty project shows "create your first issue" — a single clear action that guides users immediately.
