# Playwright

Playwright is a browser-automation tool. In the supplied source it is positioned as the browser-access layer for tasks that need a real logged-in browser or cannot be handled cleanly through an API.

## Claude MCP Use Case

The article describes a Playwright MCP connected through a browser extension and an already logged-in account. Its example has Claude navigate LinkedIn, distinguish a Connect button from Follow, and send a personalized request; it also frames Playwright as a browser fallback for pages too large or dynamic for Firecrawl. These are source-described workflows, not independent verification or a recommendation to automate restricted actions. ^[raw/articles/xarticle-youre-using-claude-wrong-if-you-dont-have-these-6--2080083376976044193.md]
