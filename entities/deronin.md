# DeRonin

X creator (@DeRonin_) who posts about AI coding workflows, token economics, and cost optimization for developers using vibe coding tools like Claude Code, Cursor, and Aider.

## Overview

DeRonin documents practical systems for cutting AI coding bills by 60-80% without reducing shipping speed or code quality. He also extends that same cost-routing mindset into a broader business claim: a solo operator can run an AI services agency if the production layer is routed to the right low-cost model and the human stays on strategy, QA, and client judgment.

## Key Arguments

- **Context discipline > model selection**: Most token waste comes from re-sending the same unchanged context on every turn, not from using expensive models. Fix upstream context discipline before switching models.
- **Model routing by task tier**: Premium models for the small fraction of high-stakes architectural or security decisions; Kimi 2.6 for the bulk of production implementation.
- **Five token traps**: (1) Re-sending entire repo on every turn, (2) tool call loops that spiral, (3) premium models on trivial tasks, (4) streaming when batching would do, (5) "just in case" context includes.
- **Solo agency thesis**: productize a narrow retainer offer, route routine delivery to AI, and keep the human on intake, QA, and relationships.
