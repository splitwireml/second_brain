# Anthropic

AI safety and research company founded by Dario Amodei and others. Makers of the [[claude]] family of LLMs and the [[claude-code]] terminal agent.

## Key Products

- **[[claude]]** — Frontier LLM family (Haiku, Sonnet, Opus, Mythos)
- **[[claude-code]]** — Terminal-based coding agent
- **Cloud Platform** — API + managed agent infrastructure
- **Cloud Code** — Desktop IDE + agent interface

## Notable People

- Dario Amodei — CEO
- [[eric-mishra]] — Researcher focused on coding agents

## Events
