# Nano Banana

Nano Banana is described by the supplied source as an image-generation model suited to realistic-looking shots and text-heavy advertising creative.

## Claude MCP Use Case

The article presents a Nano Banana MCP as a way for Claude to generate images directly, using a lobster-on-a-Mac-mini test prompt as an example. It also describes a reference-photo furniture workflow that produces multiple product-shoot angles and catalog assets. These are source-described examples rather than independently verified model benchmarks. ^[raw/articles/xarticle-youre-using-claude-wrong-if-you-dont-have-these-6--2080083376976044193.md]

## Character-sheet role in AI UGC (2026-08-08)

Machina's source uses Nano Banana to generate a full-body presenter from a fixed photoreal headshot and to create before/after variants of the same character. The exact headshot and full-body images are then attached to every clip without recropping or regeneration. The source says the fixed freckles, hair strands, face, outfit, and reference wording are identity anchors; this is source-described workflow guidance, not an independent consistency benchmark.^[raw/articles/xarticle-how-to-build-an-ai-ugc-factory-in-claude-code-2085362363214201033.md]

The same source uses Nano Banana for a one-time product still with quoted label text, material description, real size, and a large brand name, then repeats that product description in every clip prompt. It also feeds the headshot back with a “SAME character” instruction to produce two states whose change is shown across an edit. No model version, API, prompt interface, or file handoff is specified beyond these source-preserved prompts.^[raw/articles/xarticle-how-to-build-an-ai-ugc-factory-in-claude-code-2085362363214201033.md]
