# rody

rody (@0x_rody) is an X creator writing practical Claude Code orchestration guides, especially around when to escalate from a solo session to subagents, Agent View, and full agent-team collaboration.

## Known For

- [[agent-teams]] — seven-step playbook for moving from sequential solo work to a parallel Claude agent workforce
- [[claude-code-subagents]] — clear boss-worker framing for repeatable delegated tasks such as review, test, and docs

## Core Ideas

- Treat Claude Code orchestration as a ladder: subagents for isolated repeatable work, Agent View for several independent sessions, and Agent Teams for genuinely interdependent multi-file work.
- Route expensive reasoning to the lead agent and cheaper execution to teammates so parallelism does not automatically multiply spend.
- Add explicit permissions and budget caps before running multiple agents in parallel.
