# Whisper

OpenAI's general-purpose speech recognition model. A large transformer model trained on 680K hours of multilingual and multitask supervised data from the web. Supports transcription, translation, and language identification.

## Variants

- **Whisper (base)**: Smallest model, fast transcription
- **Whisper large-v3**: Best accuracy, 32kHz output
- **Faster Whisper**: CTranslate2 reimplementation, 4x faster with same accuracy
- **Insanely Fast Whisper**: Optimized for Apple Silicon, up to 197x real-time on M4 Max
