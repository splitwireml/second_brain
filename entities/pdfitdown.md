## Overview

**PdfItDown** is a Python library by [[astra-bertelli]] that converts various file formats to PDF. It serves as the backbone of [[ingest-anything]]'s text ingestion pipeline, handling the conversion of non-PDF formats (docx, csv, json, xml, images) into PDF for text extraction.

- **GitHub:** https://github.com/AstraBert/PdfItDown
- **Documentation:** https://pdfitdown.eu
