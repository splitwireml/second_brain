# Fokki

X creator (@0x_fokki) documenting AI-native video and animation production as commercial workflows rather than prompt toys.

## Overview

Fokki's June 2026 source frames animation as a modular pipeline built from specialized tools: script generation, frame generation, motion, voice, music, and orchestration. The emphasis is not on one breakthrough model but on connecting several narrow systems into a repeatable production line.

The July 2026 viral-video source shifts the same operating style upstream into research: track 40 faceless channels in a lane, score channel-relative outliers, separate topic from format, use Claude to extract reusable shapes, then feed scripts into CapCut and Make so publishing results flow back into the research sheet.^[raw/articles/xarticle-how-i-predict-viral-videos-before-they-explode-2074798903124259223.md]
