# YouTube

Google's video platform — 2B+ monthly active users. Primary distribution channel for AI-generated content, tutorials, and long-form video. Key for [[reelmeal]]-style utility apps that use the YouTube IFrame API.

## Key Facts

- Owned by Google (alphabet subsidiary)
- Search engine rank #2 globally after Google itself
- YouTube Shorts: 50B+ daily views
- API exposes full programmatic control (seek, pause, loop) — used in [[reelmeal]]
