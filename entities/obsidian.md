# Obsidian

Local-first Markdown knowledge management app. Builds a vault of interlinked notes that can be used as an agent context source, second brain, or PKM system.

Machina's source describes a business-vault use of Obsidian organized into offer, client, voice, playbooks, and rulings; corrections become standing rules in the rulings note, while custom agents receive only the needed vault slice. This is source-described workflow evidence, not a claim about an Obsidian product feature. ^[raw/articles/xarticle-how-to-build-and-scale-a-one-person-business-with--2081017272924361162.md]

## Seedance reference-bible workflow (2026-08-04)

Machina's source uses Obsidian as a folder-like reference bible rather than a free-form notebook. Each world or character gets linked pages for the idea, locked colors/style, character sheets, reference images, and exact prompts that worked; use one page per asset plus an index page pointing to the individual assets. The source says this external memory matters because one generation may draw on 30 images, 10 video clips, and 10 audio clips. ^[raw/articles/xarticle-how-to-master-seedance-25-full-course-2084666171446726767.md]

After every generation session, the workflow asks Claude for one short note on what worked and updates the index page to point to it. This is source-described organization and review practice, not a claim about an Obsidian feature or an independently measured speed improvement. ^[raw/articles/xarticle-how-to-master-seedance-25-full-course-2084666171446726767.md]

## AI UGC research vault (2026-08-08)

Machina's source uses an Obsidian folder of Markdown notes as the memory layer for ad research. Each winning-ad note contains the live link, word-for-word transcript, hook family, timed hook/pain/mechanism/proof/CTA map, proof device, CTA wording, and a one-line reason it wins. The notes feed `hooks.md`, `ctas.md`, and one map-of-content note per niche; the link is treated as the receipt that keeps a swipe file from rotting. This is source-described organization, not a claim about an Obsidian feature.^[raw/articles/xarticle-how-to-build-an-ai-ugc-factory-in-claude-code-2085362363214201033.md]

The source says scripts written from ten captured winners outship a blank page because the vault exposes transferable hook shapes while keeping the persuasion record separate from capture details. It does not specify plugins, schemas, automation commands, or a sync mechanism for this ad vault.^[raw/articles/xarticle-how-to-build-an-ai-ugc-factory-in-claude-code-2085362363214201033.md]
