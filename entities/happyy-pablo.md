# Shubham Sharma

Shubham Sharma (@HappyyPablo) is an X creator and builder working on open vision-language models for video understanding, especially systems that agents can call inline for dense captioning and temporal retrieval.

## Overview

This source centers on Sharma's release of [[marlin-2b]], a 2B-parameter video VLM positioned as a lightweight open alternative for extracting structured event information from videos.

## Key Content

- Released [[marlin-2b]] as an open model for video captioning and natural-language timestamp retrieval
- Framed the model around agent-friendly video understanding rather than general-purpose multimodal chat
- Benchmarked the model against larger systems like [[gemini]] while keeping the footprint small enough for inline use cases
