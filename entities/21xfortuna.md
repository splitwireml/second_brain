# 21xFORTUNA

21xFORTUNA is an X creator whose local July 2026 thread describes an AI-assisted property-listing walkthrough service for Airbnb hosts. This page is based on one local source; the author's identity, client results, and earnings are not independently verified.

## Source contribution

The thread describes a low-equipment workflow that turns listing photos into cinematic first-person walkthrough videos using Claude through an MCP connector, then sells the finished asset to hosts. Its replies add the important operating constraints: permission to reuse listing photos, usage rights, revision limits, output specifications, trust, and support margin. ^[raw/articles/thread-21xFORTUNA-2078982946707435591.md]

The source claims $997 in one week and $200 per video, but those figures remain source-reported. The durable wiki value is the example of [[ai-video]] delivered as a vertical, outcome-oriented [[services-as-software]] offer rather than a generic “AI video” product.
