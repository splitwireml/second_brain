# Kenny1st (@0xKenny1st)

Kenny1st is an X creator sharing source-described workflows for AI-generated cinematic websites, 3D-scroll hero sections, and skill-assisted website assembly.

## Detailed free-tool website workflow

The July 14, 2026 X Article, **“How to Build a $10,000 Website With Free AI Tools (No Code, No Design Skills),”** uses a Paris travel website to document a complete production chain. The named tools are **Pinterest** for references; **ChatGPT** for image recreation, camera prompts, and copy; **Flow AI** for start-frame/end-frame video transitions; **Clipchamp** for clip merging, speed changes, and transitions; **EZGIF** for video-to-JPG frame extraction; **Antigravity IDE** for scroll animation and integration; **Google AI Studio** for section design and code export; and **Cloudinary** for direct image URLs. These are source-described tool roles, not independently verified capability claims. ^[raw/articles/xarticle-10k-website-free-ai-tools-2077042196155363401.md]

The workflow is:

1. Create three hero keyframes in ChatGPT: a 16:9 plane-window image with text removed and a widened frame, a palette-matched Eiffel Tower image, and an intermediate cloud image.
2. Upload all three to Flow AI and generate two clips in start/end-frame mode: plane window → clouds and clouds → Eiffel Tower. Use ChatGPT for short camera-movement prompts.
3. Merge the clips in Clipchamp, slightly increase playback speed, add a transition, and export.
4. Convert the merged video in EZGIF using approximately 10 seconds and 30 fps, then extract the JPG ZIP archive.
5. Open the project in Antigravity IDE, drag the frame folder into the project and AI chat, request a smooth scroll animation with no extra components, and inspect the local-host preview.
6. Design the surrounding sections in Google AI Studio from Pinterest references, specifying values such as a 900px banner, 54px medium-weight headline, white text, solid black background, and blurred glassmorphism cards. Generate section copy with ChatGPT.
7. Export Google AI Studio code through **Code → Export → Download as ZIP**, extract `src`, and give it to Antigravity with a prompt to integrate the sections into the existing scroll animation.
8. Apply targeted final changes in Antigravity: centered hero text and CTA, gradient card backgrounds, Cloudinary-hosted replacement images, smooth hover effects, entrance animations, and small interactions. ^[raw/articles/xarticle-10k-website-free-ai-tools-2077042196155363401.md]

## 3D-scroll skill-pack workflow

The July 23, 2026 thread recommends selecting two or three motion or color references from Pinterest or Dribbble, recreating them as AI-generated images and then video, and giving the resulting video to a skill pack inside Cursor or another IDE. The skill is described as carrying smooth-scroll logic and implementation practices so the builder can request a 3D-scroll hero without writing custom scroll logic or learning an animation library. These capability and agency-cost claims are source-described, not independently verified. ^[raw/articles/thread-0xKenny1st-2080369523765436623.md]
