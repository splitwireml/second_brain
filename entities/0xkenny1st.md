# Kenny1st (@0xKenny1st)

Kenny1st is an X creator sharing source-described workflows for building 3D-scroll hero sections with Claude skill files and AI-generated video references.

## 3D-scroll skill workflow

The July 23, 2026 thread recommends selecting two or three motion or color references from Pinterest or Dribbble, recreating them as AI-generated images and then video, and giving the resulting video to a skill pack inside Cursor or another IDE. The skill is described as carrying the smooth-scroll logic and industry-standard practices so the builder can request a 3D scroll animation hero section without writing custom scroll logic or learning an animation library.
