# Perplexity

Perplexity is an AI research and search service. The supplied source focuses on its MCP integration rather than documenting the broader product independently.

## Claude MCP Use Case

AI with Remy's article describes a Perplexity MCP that runs research from inside the active Claude conversation, preserving context instead of requiring a separate subscription session. The source's example is a weekly AI-news research agent working alongside an email-designer agent for a newsletter workflow. These are source-described integrations, not independently verified product behavior. ^[raw/articles/xarticle-youre-using-claude-wrong-if-you-dont-have-these-6--2080083376976044193.md]
