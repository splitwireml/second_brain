## Overview

**Figma** is a collaborative interface design tool. Known for its accessible empty state that shows a canvas with a toolbar ready to use.

## Key Facts

- Founded: 2012
- Headquarters: San Francisco, CA
- Type: SaaS design collaboration tool

## Empty State Design

Figma's empty file shows a canvas with a toolbar ready to use — giving new users immediate context on what the product does and how to interact with it.
