## Overview

**Asana** is a project management and team collaboration tool. Known for using sample data in empty states to show users what a populated dashboard looks like.

## Key Facts

- Founded: 2008
- Headquarters: San Francisco, CA
- Type: SaaS project management tool

## Empty State Design

Asana shows a sample project with tasks already filled in, giving users a mental model for how their own data will look.
