# Hallmark

Hallmark is an open-source design skill from nutlope. A local July 2026 X bookmark describes it as a way to give Claude Code, Cursor, or Codex design rules and interface principles before they generate UI or landing pages, aiming to reduce generic “slop design.” The post recommends installing it with `npx skills add nutlope/hallmark`; these capability and quality claims are source-reported and were not independently tested here.^[raw/articles/thread-yigitakinkaya-2075510941131678039.md]

## Intended use

- Front-load visual and interface guidance before implementation.
- Apply the same design-sensitive workflow to UI and landing-page generation.
- Reduce the interchangeable look the source associates with AI-generated sites.
