# Lemlist

Lemlist is the outbound sequencer/platform discussed in Michel Lieben's 2026 cold-email playbook. The source describes Charles Tenot as its CEO and says the platform sees 20,000 signups/month; those identity, scale, and performance details are source-described claims.^[raw/articles/xarticle-the-complete-cold-email-playbook-for-2026-its-a-di-2083199326004838508.md]

## Source-described operational roles

- **Engagement-derived targeting:** Lemlist merges the spam folders of a whole team into one list, letting the team identify companies whose outbound has already landed in spam and reach out with that failure as context.
- **Personalization:** The playbook uses Lemlist's earlier reputation for personalized images as an example of a pattern interrupt that can become saturated and later return.
- **Claude-connected execution:** Around 1,500 companies are reported to run Lemlist through Claude each month. ColdIQ GTM engineers reportedly prompt an entire campaign build, leave for breakfast, and return about 30 minutes later to review a finished draft with the list uploaded and every touchpoint placed.
- **Deliverability:** Lemlist's warmup layer is reported to watch 50,000 domains and correct deliverability shifts within 24 hours; the source contrasts renting this revenue-critical infrastructure with building a custom sender that grows into secondary mailboxes, warmup, rotation, and a spam problem.

The source does not specify Lemlist API endpoints, model/version choices, MCP server names, prompt text, configuration values, list file format, touchpoint schema, or independent measurements of the reported adoption, domain coverage, timing, or deliverability outcomes. Preserve these as source-described capabilities and claims, not verified product facts.^[raw/articles/xarticle-the-complete-cold-email-playbook-for-2026-its-a-di-2083199326004838508.md]
