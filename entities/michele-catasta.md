# Michele Catasta

Michele Catasta (@pirroh) is an AI engineering leader and X author writing about production agent systems, especially how coding agents improve when evaluation, harness changes, and context memories are wired into a continual improvement loop.

## Notable Source

- **Continual Learning for Agents** — argues that closed-frontier-model agents can still learn without weight updates by improving the harness and context layers around the model. The Replit Agent example combines offline app-building evals, online A/B tests, production trace clustering, and human launch gates to turn user failures into better releases. ^[raw/articles/xarticle-continual-learning-for-agents-2074118901143679414.md]
