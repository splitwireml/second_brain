# Supertone

**Supertone Inc.** is a speech technology company specializing in lightweight, on-device text-to-speech systems. Developer of [[supertonic-3]], an open-weight TTS model with 31-language coverage.

## Products

- **Supertonic 3** — Current flagship, ONNX-based 99M parameter TTS model, 31 languages
- **Supertonic 2** — Predecessor with 5-language support

## Technical Profile

| Attribute | Value |
|-----------|-------|
| **Model** | [[supertonic-3]] (99M params, ONNX) |
| **License** | OpenRAIL-M (model), MIT (sample code) |
| **Languages** | 31 |
| **Inference** | CPU-only, no GPU required |
| **Platform** | ONNX Runtime |
