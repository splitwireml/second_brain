# Apify

Apify is described in the supplied source as a broad library of scrapers for surfaces such as Google Maps, TikTok, ecommerce sites, Reddit, comment threads, and lead lists.

## Claude MCP Use Case

AI with Remy's article presents Apify as the breadth-first choice in the six-tool stack. The source describes using an Apify MCP to analyze a competitor's X account, including follower data, 21 posts with metrics, and a writing-style breakdown. It also mentions a custom skill built on top of Apify for turning X threads or article links into clean documents. These are source-described workflows, not independent capability or performance verification. ^[raw/articles/xarticle-youre-using-claude-wrong-if-you-dont-have-these-6--2080083376976044193.md]

## Reddit MCP scraping variant

Chris's local X Article describes connecting the Apify MCP at `mcp.apify.com` to Claude, asking in plain English for a suitable Reddit scraper actor, and requesting every post and comment from a selected subreddit for the previous three months. The source supplies no actor name, schema, authentication, pagination, or independent capability test; this is a source-described workflow role. ^[raw/articles/xarticle-make-money-with-ai-agents-on-reddit-full-guide-2086455451429060984.md]
