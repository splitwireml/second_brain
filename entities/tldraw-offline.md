# tldraw offline

tldraw offline is the source-described file-based desktop application for using tldraw’s infinite canvas locally. The launch article says it has no accounts and no server: users can diagram, whiteboard, annotate, wireframe, embed media, and save files while offline. ^[raw/articles/xarticle-introducing-tldraw-offline-2077784657869902121.md]

## Agent interface

The article presents local AI-agent access as a central feature. Agents such as Claude Code, Codex, or Pi can access, edit, and add scripts to tldraw offline files. Through latent features of the tldraw SDK, scripts can create shapes, import assets, listen for changes, respond to external data, and communicate with other software. Persistent scripts load whenever a file loads, so a file can operate as a small application of its own. These are source-reported capabilities, not an independent compatibility test. ^[raw/articles/xarticle-introducing-tldraw-offline-2077784657869902121.md]
