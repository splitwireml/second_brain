# jaffa

jaffa (@dsqjaffa) is the author of a local X Article describing a source-claimed content-research workflow that connects [[virlo]] agents to TypeSafe AI's [[jev]] for fast, typed video-selection decisions before human scripting. The article is a product/operator account, not independent validation of the tools or outcomes.^[raw/articles/xarticle-jev-is-insane-for-marketing-2102054148925526206.md]

## Source-described workflow

The author directs an operator or Claude Code-style agent to collect a niche, brand name, competitor names, and target platforms (TikTok, Instagram, YouTube Shorts); draft and confirm the keyword mix; save the resulting agent ID; then run each surfaced video through Jev. The requested outputs are Noul worth-scripting probability, Choice hook/format/angle, a Score against that creator's own baseline, and confidence per call. Only results passing the unspecified Noul threshold are handed to the user; the top result becomes an adapted beat-by-beat script rather than a link list.^[raw/articles/xarticle-jev-is-insane-for-marketing-2102054148925526206.md]

## Evidence boundary

The source supplies no credential-handling method, exact threshold, agent schema, keyword-ranking algorithm, API response schema, retention policy, or independently reproducible benchmark. Its counts, cost, latency, user-base, and accuracy claims remain source-described.^[raw/articles/xarticle-jev-is-insane-for-marketing-2102054148925526206.md]
