# Romario (@bateshkaaa)

Romario is an X creator documenting source-described Claude Code workflows for producing agency-style marketing websites with a small, repeatable production pipeline.

## Constraint-first website workflow

The supplied article argues that premium-looking output comes from explicit constraints rather than a vague request to “make it beautiful.” Its workflow is:

1. Install Claude Code and load frontend-design plus UI/UX ruleset skills into `.claude/skills/`.
2. Collect three niche-specific design references from Awwwards or Dribbble; capture the hero, one content section, and footer from each.
3. Give Claude five prompt blocks: audience, one conversion action, reference files, implementation stack, and a ban list for generic design choices.
4. Run separate typography, spacing, and motion polish passes instead of asking for all changes at once.
5. Check every page at 375px width, then ship through GitHub and Cloudflare Pages.

The article presents the resulting time, pricing, and progression claims as practical guidance: first sites take about six hours, later sites become a two-hour pipeline, and the output can be positioned against agency-priced work.
