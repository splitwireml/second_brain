## Definition

A system for generating $10K/month using AI-generated UGC videos promoted across TikTok, Instagram Reels, YouTube Shorts, Facebook, and Snapchat Spotlight, with affiliate clicks via Glitchy and content iteration via Adaptive agent.

## The Full Loop

1. **Select offer** — pick trending products from TikTok, find their scripts via transcription
2. **Feed brief to Adaptive agent** — generates 10 hook angles + 3 scripts per angle
3. **MakeUGC** — turn scripts into AI avatar UGC videos in minutes
4. **Quality check** — "would you stop scrolling for this?"
5. **Post everywhere** — same content, every platform, 3x/day minimum
6. **Iteration** — agent reads performance data and generates next batch

## Why This Compounds

Every cycle the content gets sharper. Every data point sharpens the next script. Not starting from zero every time — the system compounds.

## Tools

- **Glitchy** — affiliate network ($0.80/click)
- **Adaptive** — AI agent platform for content brief + iteration
- **MakeUGC** — AI avatar video generator
