# UI Design

Visual design of user interfaces — layout, typography, color, components, and interaction patterns. In the AI era, the quality challenge is not only making a page function but giving it enough design direction to avoid interchangeable defaults.

## Agent-assisted UI quality

A local July 10, 2026 X bookmark describes [[hallmark]], an open-source design skill that can be added to Claude Code, Cursor, or Codex with `npx skills add nutlope/hallmark`. The source says the skill teaches design rules and interface principles from the start, targeting UI and landing-page generation and countering what it calls “slop design”: working but visually generic pages that resemble other AI-produced sites.^[raw/articles/thread-yigitakinkaya-2075510941131678039.md]

Because the local source is a short post and no external inspection was authorized for this ingest, the installation, compatibility, and quality claims remain source-reported.^[raw/articles/thread-yigitakinkaya-2075510941131678039.md]

## Playable game HUD and interaction brief

The July 27, 2026 [[zeuuss-01]] source treats a playable browser game as a concrete UI specification. For **Sands of the Lost Carpet**, the HUD places score top-right, coin counter, a BOOST energy bar, 3 hit-point hearts top-left, and a distance meter. The start screen shows the title + “Tap to Fly”; the game-over screen shows score + “Retry” button; the brief also calls for rising difficulty, a coin pickup sound, and a boost whoosh. ^[raw/articles/thread-zeuuss_01-2081837342726214087.md]

The interaction model keeps desktop and mobile controls explicit: Left / Right (A-D or arrow keys, or tilt/drag on touch) steer the carpet; Up / Down (W-S or swipe) climb / dive; Space / tap triggers BOOST, a short speed burst limited by an energy meter. The game loop is auto-forward flight, with a 3-hit-or-crash run boundary, and the requested delivery bar is “smooth, juicy, and instantly playable in the browser.” ^[raw/articles/thread-zeuuss_01-2081837342726214087.md]

The visual brief constrains the interface context as well as the mechanics: vibrant stylized-cartoon art, a saturated gold-teal-magenta palette, warm sunset light, glowing bloom, particle sparkles, a collapsing golden treasure cavern, and a lush oasis valley with turquoise river, waterfalls, and a domed palace-city at sunset. Original assets and characters only are permitted; the source bans logos, brand marks, real game titles, and Disney designs. These are requested design behaviors and constraints, not independently tested usability or performance results. ^[raw/articles/thread-zeuuss_01-2081837342726214087.md]
