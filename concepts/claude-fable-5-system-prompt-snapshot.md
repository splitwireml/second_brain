# Claude Fable 5 System Prompt Snapshot

A raw snapshot of a purported Claude Fable 5 system prompt that is useful less for jailbreak novelty than for product-surface reconnaissance.

## Why the source matters

Even if treated cautiously, the leaked prompt is interesting because it bundles public-product positioning and tool exposure in one place. It explicitly describes Fable 5 as a Mythos-class model above Opus, names adjacent surfaces like Claude Code and Claude Cowork, and references beta agents in Chrome, Excel, and PowerPoint.

## Main takeaway

System prompts are not only alignment scaffolding; they are also compressed product maps. They reveal what the assistant has been told to say about model hierarchy, supported tools, escalation boundaries, and how to answer product questions when internal details may have changed.

## Caution

This source should be treated as a snapshot, not an unquestioned ground truth. Its strongest value is comparative: it shows how Anthropic packages capabilities and refusal behavior inside a single instruction layer.
