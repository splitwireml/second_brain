# AI Engineer Path

Building AI systems for companies — highest-skill, highest-pay path on the list, and most defensible.

## What It Is
A software engineer builds amazon.com. An AI engineer adds the chatbot that understands "where's my package" and pulls the answer from your order database. They wire AI models into software products: chatbots, recommendation systems, document search, agents, internal tools.

## The 5-Layer Pyramid
1. **Software foundation** — Python, APIs, git, basic full-stack
2. **Basic AI integration** — OpenAI APIs, Hugging Face pre-trained models
3. **Intelligent systems** — LangGraph, MCP, RAG + vector databases
4. **Scale without breaking** — Docker, AWS/GCP, Redis caching
5. **Strategic operations** — LLMOps, evaluation frameworks, cost governance, model routing

## Compensation
- Big tech salaries: $200-354k+
- Solo freelance/contract: $100-300/hour
- Retainer clients: $5-15k/month per company
