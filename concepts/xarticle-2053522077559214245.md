# $15,400 from YouTube + TikTok + Instagram Using Only Claude & $20

X Article by [[shmidt]] (@shmidtqq) posted May 10, 2026. A detailed playbook for building a faceless UGC content business using Claude, ElevenLabs, and CapCut across YouTube, TikTok, and Instagram simultaneously.

## Overview

The article documents a $15,400/month income system built with:
- **Claude** ($20/month) — scriptwriting, metadata generation, workflow orchestration
- **ElevenLabs** — voiceover (custom voice cloning)
- **CapCut** — video assembly
- **Python publish.py** — auto-publishing to all three platforms via APIs

## Key Points

| Platform | Revenue per million views | Bottleneck |
|---|---|---|
| YouTube long form | $4,000–$30,000 RPM | script quality |
| YouTube Shorts | $50–$400 | hook in first second |
| TikTok Creator Rewards | $400–$1,500 | watch time |
| TikTok Shop affiliate | $2,000–$20,000 | product fit |
| Instagram Reels Bonus | $200–$1,200 | shareability |
| Instagram brand deals | $500–$5,000/post | follower count |

- YouTube long form (AdSense): $5,200
- YouTube Shorts: $480
- TikTok Shop affiliate: $3,100

### Content Pipeline

One topic → Claude research → Claude script → ElevenLabs voice → CapCut assembly → extract 4 shorts → publish to all 3 platforms = 13 pieces of content in ~3 hours.

### Monetization Timeline

- Months 1–2: Build only, no monetization
- Month 3: AdSense + affiliate links
- Month 4: TikTok Shop
- Month 5: Instagram brand deals ($300–$800/post at 10K followers)
- Month 6+: Digital product launch

### Auto-Publishing

Full Python script (`publish.py`) provided that uses YouTube Data API, Instagram Graph API, and TikTok Content API to post in one command.
