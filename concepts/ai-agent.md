# AI Agent

An AI agent is a system that uses an LLM to autonomously plan and execute multi-step tasks — observing environment, selecting actions, and iterating toward a goal without continuous human input.

## Key Concepts

- [[agent-orchestration-patterns]] — how multiple agents work together
- [[agent-memory-architecture]] — memory systems for agents
- [[multi-agent]] — multi-agent coordination
- [[hermes-agent]] — an agent framework with skills and delegation

## Distinction from Chains

- **Chain**: Pre-defined sequence of steps, fixed logic
- **Agent**: Dynamically decides next action based on LLM reasoning
