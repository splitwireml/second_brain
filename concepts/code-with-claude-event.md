# Code with Claude Event

Anthropic's developer conference series showcasing Claude's coding capabilities, model roadmap, and platform infrastructure.

## Events

### San Francisco (2025)
- First ever Code with Claude event
- Headline: Opus 4 launch
- Key milestone: Claude could run for a few minutes and build an entire feature without human check-in

### London (2026-05-21)
- Second event; first held outside San Francisco
- Speakers: Boris (opening), Lisa (Research PM), Angela + Caitlin (Cloud Platform), Kat (Cloud Code)
- Key announcements:
  - Opus 4.7 and Mythos Preview capabilities
  - Claude Managed Agents with self-hosted sandboxes + MCP tunnels
  - Cloud Code routines + desktop app
  - Advisor strategy for cost-efficient frontier quality

## London Event Structure

1. **Boris (Opening)** — Personal story of learning to code on TI-83 calculator; Spotify (1,000 PRs/month, 90% migration time reduction), Binti (20 days off foster-family licensing)
2. **Lisa (Research PM)** — Model capability curve; Task Horizon concept; scaffolding reduction as models get smarter
3. **Angela + Caitlin (Cloud Platform)** — Claude Managed Agents demo with fictional "Counter" company; multi-agent orchestration, outcomes, dreaming, self-hosted sandboxes, MCP tunnels
4. **Kat (Cloud Code)** — Desktop app, VS Code extension, routines (scheduled/webhook/API-triggered), CI Auto Fix

## Key Themes

- **Capability exponential vs. adoption linear** — gap between what AI can do and what organizations actually use
- **Task Horizon** — how long can a model work before losing the thread? Expanding from minutes → hours → continuous
- **Scaffolding reduction** — as models get smarter, agent loops/instructions/tools that used to help can hold them back
