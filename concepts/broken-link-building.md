# Broken-Link Building

Broken-link building is an SEO outreach method that finds pages or resources that no longer work, creates a credible replacement, and offers the replacement to sites still linking to the dead resource. The pitch is framed as a concrete page fix rather than a favor request.

## Operating workflow

1. **Find valuable dead pages.** Pull competitor backlink profiles, identify 404 or soft-404 pages, rank them by referring domains, and keep prospects relevant to the target topic.
2. **Recover link intent.** Use an archive such as the Wayback Machine to understand whether the old page earned links for a benchmark, tool, template, guide, interview, or original research.
3. **Build the replacement.** Match the original intent, refresh the information, and add the data, chart, or template that makes the new page genuinely linkable.
4. **Make the swap easy.** Name the exact article and dead URL, show the replacement in one line, and ask for a precise link update.
5. **Separate labor from judgment.** The source proposes using Kimi K3 for crawling, checking, sorting, and contact verification while Claude keeps the decisions about which links to chase, what to build, and how to pitch.
