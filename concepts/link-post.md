## Definition

A link-post is an X (Twitter) post that consists primarily of a bare URL with minimal or no accompanying text. The post's value is derived entirely from the linked content.

## Characteristics

- Character count: typically very low (often just the URL itself)
- Engagement: varies based on linked content quality
- Export failures: common when the source tweet cannot be read via the Bird API
- Repeat-example: [[creatorpascal]] has four bare t.co URL bookmarks whose exports failed, leaving no recoverable body beyond the link itself and reinforcing this as a recurring link-post pattern rather than a one-off.^[raw/articles/xarticle-httpstcoe9aurw47us-2070855856959209986.md]^[raw/articles/xarticle-httpstcolzp3txuywy-2071200865881350381.md]^[raw/articles/xarticle-httpstcormzwgvt3y5-2074618289150738691.md]^[raw/articles/xarticle-httpstcovqu1o5iyni-2078838553430077715.md]
- Another recent example: [[dimitar-angelov]] posted a bare shortened-URL bookmark whose export also failed, again preserving no recoverable body beyond the link itself.^[raw/articles/xarticle-httpstcoza1acztalq-2070896784449171568.md]
- Recurring-author example: [[zephyr-hg]] now has two separately ingested export-failed bare-URL bookmarks, which strengthens link-post as an author-level posting pattern instead of a one-off scrape miss.^[raw/articles/xarticle-httpstco40nwwzxwal-2055229007931601239.md]^[raw/articles/xarticle-httpstcodc4wyxqsq5-2071602748802445815.md]
- Additional provenance example: [[heynavtoor]] also has an export-failed bare shortened-URL bookmark with no recoverable body beyond the link itself, extending this pattern to another creator already known in the wiki for entirely different topics.^[raw/articles/xarticle-httpstcokuncp7vuh1-2071905311162843433.md]
- Another recurring-author example: [[shmidt]] now also has two separately ingested export-failed bare-URL bookmarks, so the pattern is not limited to one-off creators or one scrape batch.^[raw/articles/xarticle-httpstcobifvoiybki-2056038230454112601.md]^[raw/articles/xarticle-httpstcoiowc8ikxsr-2071968426562605182.md, raw/articles/xarticle-httpstcobhewgetxo2-2071994887721947226.md]
- Cross-topic recurring-author example: [[din-scales26]] is mainly tracked for outbound systems, but now has two export-failed bare shortened-URL bookmarks, showing the same link-post pattern can recur as side-channel provenance from authors better known for substantive write-ups.^[raw/articles/xarticle-httpstcobhewgetxo2-2071994887721947226.md]^[raw/articles/xarticle-httpstcomc6jkerp7q-2074893973441675651.md]
- Additional author-level provenance: [[wandermist]] now also has an ingested export-failed bare shortened-URL bookmark, but the local export preserves no recoverable destination context beyond the link itself.^[raw/articles/xarticle-httpstcoo3qwmu4xtk-2071930382581195105.md]

- Recurring-author example: [[whotfiszackk]] is mainly tracked for substantive faceless digital-product articles, but multiple local bookmarks from the account are export-failed bare shortened-URL stubs; this one adds author-level provenance without recoverable destination context.^[raw/articles/xarticle-httpstconmgxwgbnm8-2074760374243455348.md]^[raw/articles/xarticle-httpstcoit4fejrsg5-2079226781710827729.md]
