# AI Automation Path

Wiring AI into work businesses already do — high demand, lower skill floor than engineering.

## What It Is
Lead comes in → gets enriched, scored, routed, followed up, without a human pushing buttons. Invoices get read and logged. Support tickets get triaged. Content gets drafted, formatted, and queued.

## The Shift
- Old way: drag-and-drop no-code tools (Zapier, Make, n8n)
- New way: Agentic workflows built with Claude Code — natural language, self-heal, redeploy in seconds

## The DO Framework (Nick Saraev)
- **Directive** → **Orchestration** → **Execution**
- Self-annealing workflows that fix their own errors
- Cloud deployment with webhooks
- Sub-agents running in parallel

## Business Model
- Setup fees: $500-5k per workflow
- Retainers: $1-5k/month per client
- 5 retainer clients at $3k = $15k MRR with ~10 hours/week upkeep

## Proof
- [[nick-saraev]]: Runs two AI service agencies doing $160k/month combined revenue, solo-led

## Key Insight
"AI automation is the fastest path on this list from zero to paying clients. the bottleneck isn't skill. it's picking up the phone."
