# how the best software companies in the world design empty states...

how the best software companies in the world design empty states...

an empty state is what a user sees when there's no data yet.

basically the first experience after signup

the best software companies turn this moment into an onboarding tool, a product demo, and an emotional touchpoint SIMULTANEOUSLY

---

## what good empty states do:

1. they tell the user what to do next

they do this with a single CLEAR asf (like me lol) action.

for example. notion's empty page shows a cursor blinking and a subtle menu of options and linear's empty project shows "create your first issue."

figma's empty file shows a canvas with a toolbar ready to use

2. they make the action always one click away

NEVER make it two or "first go to settings, then configure your workspace, then create a project."

always have it be one button and one action with immediate value

3. they show what the product looks like with data

some companies use sample data or templates to show what a populated dashboard looks like.

for example, asana shows a sample project with tasks already filled in

this gives the user a MENTAL MODEL for how their own data will look

4. they set emotional tone

slack's empty channel says something warm and notion's empty page feels like infinite possibility.

the best empty states always make you excited to fill them rather than confused about where to start

5. they reduce anxiety

a new user looking at a blank screen thinks "i don't know wtf to do and i might break some shit"

a good empty state says "here's exactly what to do, it takes 30 seconds, and you can't possibly mess it up"

---

## the framework for designing empty states:

EVERY empty state should answer three questions in 3 seconds:

- "what is this space for?": a short headline explaining the purpose of this section

- "what should i do first?": one primary action button

- "what will it look like when i'm done?": either a preview, a template, or sample data

if your empty state doesn't answer all three, users will for sure bounce from the page and many won't come back
