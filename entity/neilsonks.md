# neilsonks

GitHub user and developer who created **image-blaster**, a repository that converts photographs into explorable 3D environments.

## Known Work

### image-blaster
- Viral GitHub repo that converts any photo into a 3D world with meshes, physics, gaussian splatting, and ambient audio
- Created reportedly using **Claude** (per reply #145 in the thread by @l43150)
- The repo's release sparked a viral thread by @CopyRebeldia that became a major discussion point about AI disruption to 3D artists

## Reception

- The tool was credited by @CopyRebeldia in the original thread as "the repo that converts any photo into an explorable 3D world"
- @CopyRebeldia credited neilsonks as the "autor original" (original author) in reply #2
